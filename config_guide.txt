AI & Credentials Reference (%APPDATA%\Cheating Mommy\credentials.txt):
  (You can edit this file directly or run update_credentials.exe to modify settings interactively)

SERVER_URL (string)
  Server endpoint URL (e.g. "https://server-784947522852.europe-west1.run.app").
  If set to "local" or left empty (""), it automatically switches to local AI mode!

LLM (string)
  "deepseek" or "gemini". Used when running locally.

MODEL (string)
  Optional model name override.
  Defaults:
  - DeepSeek: "deepseek-flash" (or custom like "deepseek-v4-pro")
  - Gemini: "gemini-2.5-flash" (or "gemini-3-flash-preview")

API (string)
  API key for the chosen LLM (Gemini or DeepSeek) when running locally.
  (DEEPSEEK_API_KEY and GEMINI_API_KEY are also supported).

ACCESS_KEY / API_KEY (string)
  Client keys used for authentication when connecting to the remote server.

config.json reference (Application UI, Mouse, Hotkeys, OCR settings):

mouse.smooth (bool)
  Enable or disable smooth movement. If false, the cursor jumps to the target.

mouse.duration (float, seconds)
  Total time to move the cursor when speed is 0.0.
  Can be a list [min, max] to randomize each move.

mouse.steps (int)
  Number of steps for smooth movement. Higher = smoother but slower.
  Can be a list [min, max] to randomize each move.
  A single-item list (e.g., [12]) is treated as a constant.

mouse.curve_strength (float, pixels)
  Amount of curve applied to the path. 0.0 is a straight line.
  Positive values curve to one side; negative values curve to the other.
  Can be a list [min, max] to randomize each move.

mouse.speed (float, pixels per second)
  If > 0, overrides duration. The move duration becomes distance / speed.
  Can be a list [min, max] to randomize each move.
  A single-item list (e.g., [500]) is treated as a constant.

mouse.path_mode (string)
  "direct" for straight paths, "indirect" to apply a curve.

mouse.jitter (float, pixels)
  Adds random jitter to intermediate points. 0 disables jitter.
  Can be a list [min, max] to randomize each move.
  A single-item list (e.g., [2]) is treated as a constant.

ocr.lang (string)
  OCR languages to recognize separated by '+' (e.g. "rus+eng", "eng", "kaz+rus+eng").
  Defaults to "rus+eng" to accurately recognize both English and Cyrillic/Russian texts.

ocr.config (string)
  Optional Tesseract config string. Leave empty for defaults.
  Example:
  --oem 3 --psm 7 -c tessedit_char_whitelist=ABCDEFGHIJKLMNOPQRSTUVWXYZ0123456789

ocr.mode (string)
  OCR aggregation mode. "chunk" or "line".

ocr.x_thresh (float)
  Horizontal gap threshold for merging in chunk mode.

ocr.y_thresh (float)
  Vertical gap threshold for merging in chunk mode.

ocr.group_y_thresh (float)
  Vertical gap to separate different question groups.

ocr.crop_bbox (list)
  Crop the screenshot before OCR/server calls as [x, y, w, h].
  Use [] to disable cropping.

ocr.crop_clamp (bool)
  Clamp crop_bbox to the screenshot bounds if it goes out of range.

hotkeys (Keyboard and Mouse Shortcuts):
  (You can configure these by launching tools/hotkey_configuration.exe or editing config.json)
  Supports keyboard keys, mouse buttons, multi-clicks, and modifier combinations (ctrl+, alt+, shift+, win+):
  - Mouse buttons: "left", "right", "middle" (wheel click), "x1" (thumb back), "x2" (thumb forward), "wheel_up", "wheel_down"
  - Multi-click triggers: "triple_left" (triple-click left mouse!), "double_left", "triple_right", "triple_middle", "triple_x1", etc.
  - Modifier examples: "triple_left", "ctrl+x1", "alt+middle", "shift+p", "ctrl+p", "x1"

hotkeys.toggle_commands (string)
  Key or mouse button that toggles command hotkeys on or off (default "l").

hotkeys.window_visibility (string)
  Key or mouse button that toggles the AI window overlay visibility (default "k").

hotkeys.turned_on_by_default (bool)
  If true, action hotkeys are enabled at startup. If false, toggle key enables them.

hotkeys.visible_by_default (bool)
  If true, the window is shown on startup. If false, it starts hidden.

hotkeys.answer_key (string)
  Key or mouse button to trigger answer screenshot, AI solve, and auto-click (default "p").
  Example: "triple_left", "p", "x1", "ctrl+x1", "middle".

hotkeys.copy_key (string)
  Key or mouse button to copy the answer to clipboard (default "o").
  Example: "o", "x2", "ctrl+x2", "double_middle".

hotkeys.info_key (string)
  Key or mouse button to request AI log-only response with Google search (default "i").
  Example: "i", "ctrl+middle", "alt+x1", "triple_right".


ui.window_pos (string or list)
  "mouse" to show near the cursor, "default" to keep current position.
  "mouse+(x,y)" or "mouse-(x,y)" to apply offset from mouse-centered position.
  Or [x, y] to place the window at a fixed screen position.

ui.window_size (list)
  Window size as [width, height]. Minimum 200x120.

ui.transparency (float)
  Window opacity from 0.1 to 1.0.

ui.background_color (string)
  Window background color (hex like "#111111").

ui.border_color (string)
  Border color for the list area (hex like "#2a2a2a").

ui.border_thickness (int)
  Border thickness in pixels for the list area.

ui.header_visible (bool)
  Show or hide the window title bar.

ui.logs.history_max (int)
  Max number of entries to keep in the on-screen AI results list.

ui.logs.size (int)
  Log text size (minimum 8).

ui.logs.text_color (string)
  Log text color (hex like "#ffffff").

ui.logs.action_log (bool)
  If true, logs keypress actions like "p is pressed" and "o is pressed".

ui.hint.visible (bool)
  Show or hide the bottom hint text.

ui.hint.color (string)
  Hint text color (hex like "#888888").

ui.hint.size (int)
  Hint text size (minimum 7).
